About AGAG

AGAG (Agent Accessibility Guidelines) is a dual-legibility standard extending WCAG 3.0 to include autonomous agents as first-class users of the web. Developed by Thea Eaton / Agent 508.

Human-facing site: www.openaix.org

The Principle Behind This Page

This subdomain is a live implementation of AGAG-E2: Provide Direct Structured Access When Possible.

And AGAG-C4: The web cannot treat all bots as abuse if some bots are literally performing accessibility support.
